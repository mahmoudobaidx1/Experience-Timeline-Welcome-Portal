# Experience Timeline & Welcome Portal

A clean, responsive multi-page web project built with pure HTML5 and CSS3. It features an interactive timeline grid showcasing educational milestones from high school to university, linked to a stylized welcome landing page.

## ✨ Features

* **Responsive CSS Grid Layout:** Automatically adjusts the number of columns based on screen width (`auto-fill`, `minmax`).
* **Interactive Hover Effects:** Smooth color transitions using CSS custom properties (`--main_color---`).
* **Dark Theme UI:** Sleek black background with contrasting grey cards and pastel purple accents (`#9d8ad8`).
* **Mobile-First Media Queries:** Adapts layout direction and card sizing seamlessly for tablet and desktop viewports.

## 📁 Project Structure

```text
├── quiz9.html          # Main page displaying the interactive Experience timeline grid
├── style8.css          # Stylesheet for the Experience page (Grid, Flexbox, Media Queries)
├── welcomehome.html    # Destination landing page linked from the timeline cards
└── style9.css          # Stylesheet for the Welcome Home card layout
```

## 🚀 Getting Started

No build tools, dependencies, or servers are required to run this project.

1. **Clone or download** the repository files into a single folder.
2. Ensure all four files (`quiz9.html`, `style8.css`, `welcomehome.html`, `style9.css`) remain in the same root directory so relative links work properly.
3. Double-click `quiz9.html` to open it in any modern web browser.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and navigation links.
* **CSS3:** CSS Variables, Flexbox, CSS Grid, and responsive Media Queries.
